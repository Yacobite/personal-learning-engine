# Boolean logic: a public demo

This small synthetic learning source is provided for trying the learning engine.
It contains no private course material or learner data.

## Propositions

A proposition is a statement with a truth value: true or false.
Use P and Q to represent propositions.

## Conjunction

The conjunction P AND Q is true exactly when both P and Q are true.
The symbol for conjunction is ∧, so P AND Q can also be written P ∧ Q.

| P | Q | P AND Q |
| --- | --- | --- |
| true | true | true |
| true | false | false |
| false | true | false |
| false | false | false |

For example, if P is true and Q is false, P AND Q is false.

## Negation

NOT P reverses the truth value of P. It is also written ¬P.
If P is true, NOT P is false. If P is false, NOT P is true.
